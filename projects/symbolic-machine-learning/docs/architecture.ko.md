# 구조와 지원 범위

[English](architecture.md) | [한국어](architecture.ko.md) | [프로젝트 README](../README.ko.md)

## 두 가지 학습 경로

이 프로젝트는 신경망 가중치 대신 사람이 살펴볼 수 있는 기호 가설을 학습합니다.

```text
속성 예제                              관계 예제 + Prolog 사실
    |                                           |
Python 결정 트리 학습                  FOIL의 규칙 생성과 구체화
    |                                           |
범주형 분기를 가진 트리                허용된 술어로 구성한 Horn 절
    |                                           |
양성 경로를 연결한 논리식               PySwip을 통한 SWI-Prolog 질의
    |                                           |
참과 거짓 예측                         관계의 성립 여부 예측
```

`learning/util.py`는 데이터셋, 공통 학습 흐름과 알고리즘 등록을 담당합니다. `learning/generate.py`는 불리언 속성 개념을 생성합니다. `learning/attr_learner.py`에는 결정 트리와 논리식이, `learning/rule_learner.py`에는 규칙 표현과 FOIL 탐색 및 Prolog 연결이 들어 있습니다.

## 결정 트리와 읽을 수 있는 논리식

`dtl`은 정보 이득으로 분기 속성을 선택합니다. 정답이 같은 부분집합은 리프가 되고, 더 나눌 수 없는 경우 다수 클래스를 사용합니다. 양성 리프까지의 각 경로는 논리곱으로 변환하고, 이들을 논리합으로 연결합니다. 별도의 설명 모델 없이 학습한 분류 규칙 자체를 확인할 수 있는 구조입니다.

초기 `my-dtl`은 이득비와 모든 가지가 공유하는 후위 순회 성장 카운터를 결합합니다. 이 구현은 초기 스냅샷에 보존하고 과거 실험의 대상으로 구분합니다. 경로별 깊이 제한은 현재 깊이를 재귀 호출의 인자로 전달하므로 한 가지의 성장이 다른 가지의 깊이 예산을 소모하지 않습니다. 두 제어 방식은 서로 다르므로 결과도 구분해서 해석해야 합니다.

이득비는 분기 선택을 바꾸고, 깊이 제한은 트리의 표현 용량을 조절합니다. 두 요소를 나눈 실험을 통해 어떤 변경이 결과에 영향을 줬는지 분석합니다. 후보 학습기의 복잡도는 내부 검증 데이터에서 고르고, 후보 정책은 별도의 개발 홀드아웃으로 비교합니다. 최종 평가는 이전에 사용하지 않은 시드로 수행하며 최종 평가 예제로 정책을 고르지 않습니다.

| 등록명 | 속성 선택 | 복잡도 조절 |
| --- | --- | --- |
| `dtl` | 정보 이득 | 초기 구현 유지 |
| `my-dtl` | 이득비 | 초기 공유 성장 카운터 유지 |
| `corrected-dtl` | 정보 이득 | 입력 계약과 결정적 분기를 적용한 개선 구현, 기본값은 깊이 제한 없음 |
| `gain-ratio` | 이득비 | 기본값은 깊이 제한 없음 |
| `depth-limited` | 정보 이득 | 실제 경로별 최대 깊이 |
| `gain-depth` | 이득비 | 실제 경로별 최대 깊이 |
| `pruned-dtl` | 정보 이득 | 검증 예제로 아래에서 위로 가지치기 |

개선한 변형은 `tree_`, `tree_metrics()`, `trace(example)`를 제공합니다. 깊이는 루트에서 리프까지의 간선 수이며 루트가 리프면 0입니다. 측정값에는 깊이, 노드 수, 리프 수, 양성 규칙 수와 조건 수가 포함됩니다. `pruned-dtl`에는 별도 검증 데이터셋이 필요하며, 검증 정확도가 같으면 더 작은 트리를 선택합니다. 최종 평가셋은 가지치기에 전달하지 않습니다.

통제 벤치마크는 다수 클래스 기준과 검증으로 깊이를 고르는 `gain-depth-tuned` 조건을 추가해 총 아홉 조건을 비교합니다. 두 조건은 별도의 등록 구현이 아닌 실험 정책입니다.

개선한 변형의 예측에는 학습한 모든 특성이 필요하며 학습에서 본 적 없는 범주는 오류로 안내합니다. 명시적인 `None` 범주와 불리언 정답, 유한한 단일 범주 값을 지원합니다. 전체 학습에서 관측했지만 특정 분기에는 없는 범주는 해당 노드의 학습 다수 클래스를 사용합니다. 이 계약은 개선한 변형의 동작이며 초기 학습기는 과거 비교를 위해 유지합니다.

## FOIL과 Prolog 상태 관리

FOIL은 아직 설명하지 못한 양성 예제에서 출발해 후보 조건을 추가하며 규칙을 구체화하고, 다른 양성 예제를 설명할 규칙을 반복해서 학습합니다. Prolog 지식 베이스는 사용할 수 있는 배경 관계를 제공합니다. 학습 결과는 출력하고 질의할 수 있는 Horn 절입니다.

예측은 학습기의 문맥 관리자 안에서 수행합니다.

```python
with FOIL(dataset=dataset, recursive=True) as learner:
    learner.fit()
    result = learner.predict(example)
    print(learner.hypothesis)
```

문맥을 종료하면 학습한 목표 술어와 불러온 지식 베이스를 정리합니다. 유한 그래프의 재귀 관계는 SWI-Prolog 테이블링을 사용하며, 학습한 목표 규칙이 바뀌면 캐시된 답을 무효화해야 합니다. 유한 관계 예제에서 실행이 끝났다는 사실이 무한히 커지는 항을 포함한 임의의 Prolog 프로그램에서도 종료를 보장하지는 않습니다.

목표 술어의 선언은 실제 포함 여부를 질의하기 직전에 만듭니다. SWI-Prolog 표준 시간제한 안에서 정해 둔 답을 먼저 수집한 뒤 Python에 바인딩을 전달하므로 생성기의 반환 사이에 알람이 열린 채 남지 않도록 합니다. 임시 절의 참조는 Prolog 내부 보조 술어에서만 사용하고 정확히 제거합니다. 학습 예산을 다 써도 별도 질의 시간제한으로 정리를 시도합니다. 검증 범위는 순차 문맥과 별도 벤치마크 프로세스이며 동시에 활성화된 FOIL 문맥의 상호 격리를 보장하지 않습니다.

FOIL에는 실행 시간과 후보 평가 수, 질의 수, 규칙 수 및 규칙별 조건 수의 예산을 명시합니다. 음성 예제를 여전히 포함하는 규칙을 개선할 수 없으면 정상 결과처럼 채택하지 않고 학습 오류를 반환합니다. 예산 초과와 질의 오류, 정리 오류도 구분합니다. 평평한 목표 술어 형식과 예제 키, 지원하는 원자 및 숫자와 모순된 정답을 검사합니다. 임의의 Prolog 소스 파일을 격리하는 보안 샌드박스는 아닙니다.

기본값 `lookahead=0`은 탐욕 탐색을 유지합니다. 선택 가능한 `lookahead=2`는 양의 이득을 가진 한 조건이 없을 때 양성 바인딩을 유지하는 이득 0의 첫 조건과 두 번째 조건을 묶어 양의 결합 이득을 찾습니다. 이 탐색에도 후보 및 질의 예산을 적용합니다. 두 관계 CLI 모두 `--lookahead 2`로 선택합니다.

`predict_with_trace(example)`는 일치한 학습 규칙과 입력 바인딩을 제공합니다. 어떤 규칙이 예측에 대응하는지 보여주는 설명이며 Prolog 내부의 전체 증명 트리를 제공하지는 않습니다.

## 평가의 경계

[`experiment-report.ko.md`](experiment-report.ko.md)와 [`evaluation-guide.ko.md`](evaluation-guide.ko.md)는 초기 명령과 실험을 보존한 문서입니다. 특히 초기 잡음 실험은 정답을 복원한 뒤 학습에 사용한 예제를 포함해 평가합니다. 이 결과만으로 새로운 예제에 대한 일반화 성능을 판단할 수 없습니다. 현재 `eval-noisy`는 기본적으로 학습 80%와 깨끗한 홀드아웃 20%를 분리하고 학습 정답에만 잡음을 적용합니다. 초기 절차를 재현하려면 초기 스냅샷을 사용합니다.

개선 실험은 학습용, 검증용, 최종 평가용 예제를 분리합니다. 같은 조건의 알고리즘에는 동일한 개념과 예제, 분할 및 학습 정답의 잡음 위치를 적용합니다. 집계 그래프와 함께 예측값, 시드, 학습 규칙과 측정 시간을 남겨 예상 밖의 결과도 확인할 수 있게 합니다.

실행 시간은 측정한 컴퓨터와 프로세스의 영향을 받습니다. 생성한 불리언 개념이나 유한 그래프 관계에서 얻은 정확도가 외부 표 데이터, 자연어 또는 운영 데이터에서의 성능을 입증하지는 않습니다.

## 지원하는 입력과 범위

- 불리언 정답을 가진 생성 범주형 속성 예제
- 유한한 Prolog 사실과 명시적인 양성 및 음성 관계 예제
- 관계 학습에 필요한 SWI-Prolog 런타임을 연결한 로컬 Python 실행
- 학습한 논리 규칙 출력과 반복 가능한 명령행 실험

과제에 남아 있는 `Dataset.from_csv()`와 `Dataset.to_csv()`는 지원하는 실행 경로가 아닙니다. 이 프로젝트는 배포된 예측 서비스나 신경 기호 모델, 언어 모델 통합 에이전트에 해당하지 않습니다. 별도 프로젝트에서 사용하는 Vampire와 우주선 설계 검사기는 이 학습 경로에 필요하지 않습니다.
