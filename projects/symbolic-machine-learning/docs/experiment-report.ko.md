# 결정 트리 개선 실험

[English](experiment-report.md) | [한국어](experiment-report.ko.md) | [프로젝트 README](../README.ko.md)

## 요약

기준 결정 트리 학습기(`dtl`)와 이득비 및 트리 성장 제어 휴리스틱을 사용하는 `my-dtl`을 비교했습니다. 과제 당시 기록한 결과에서 학습 속도는 뚜렷하게 개선되었고 한 고잡음 조건의 정확도도 높아졌지만, 여러 저잡음 및 제한된 데이터 조건에서는 성능이 낮아졌습니다.

결과는 기존 측정 근거로 보존한 것입니다. 포트폴리오 재구성 과정에서는 실험을 다시 실행하지 않았습니다.

## 연구 질문

정규화된 속성 선택과 제한된 트리 성장이 잡음 데이터의 과적합을 줄이면서 학습 시간도 단축할 수 있는가?

## 평가한 변경 사항

### 이득비

기준 구현은 정보 이득으로 속성을 선택합니다.

```text
Gain(S, A) = Entropy(S) - Σᵥ |Sᵥ| / |S| × Entropy(Sᵥ)
```

`my-dtl`은 이 값을 분할 엔트로피로 나눕니다.

```text
SplitInfo(S, A) = -Σᵥ |Sᵥ| / |S| × log₂(|Sᵥ| / |S|)
GainRatio(S, A) = Gain(S, A) / SplitInfo(S, A)
```

값의 종류가 많아 데이터를 작은 파티션으로 지나치게 나누는 속성에 페널티를 줍니다.

### 트리 성장 제어

구현은 학습 예제 수를 `n`이라 할 때 최대 깊이 목표를 `floor(log2(n))`으로 설정하고, 한계에 도달하면 다수 클래스 리프를 반환합니다.

중요한 구현상 주의점이 있습니다. 현재 코드는 하나의 공유 카운터에 깊이를 저장하고 자식 서브트리를 만든 뒤 값을 증가시킵니다. 따라서 정확한 루트-리프 깊이 제한이 아니라 전역 후위 순회 성장 휴리스틱에 가깝습니다. 기록된 결과는 이상적인 가지별 깊이 제한이 아니라 실제 제출 구현을 대상으로 합니다.

## 재현 명령

의존성을 설치한 후 `projects/symbolic-machine-learning`에서 실행합니다.

```bash
python evaluate_attributes.py eval-time -a dtl -a my-dtl -s 5 -s 7 -s 10
python evaluate_attributes.py eval-noisy -a dtl -a my-dtl -c 0.3 -c 0.5 -c 0.7 -s 10 -d 5
python evaluate_attributes.py eval-noisy -a dtl -a my-dtl -c 0.3 -c 0.5 -c 0.7 -s 10 -d 10
python evaluate_attributes.py eval-size -a dtl -a my-dtl -t 0.3 -t 0.5 -t 0.7 -s 10 -d 5
python evaluate_attributes.py eval-size -a dtl -a my-dtl -t 0.3 -t 0.5 -t 0.7 -s 10 -d 10
```

스크립트는 기본 고정 시드(`42`)를 사용하지만 실행 시간은 장비와 소프트웨어 환경의 영향을 받습니다.

## 기록된 결과

### 학습 시간

| 예제 수 | 속성 수 | `dtl` | `my-dtl` | 기록된 감소율 |
| ---: | ---: | ---: | ---: | ---: |
| 32 | 5 | 0.271 ± 0.004 ms | 0.151 ± 0.002 ms | 44% |
| 128 | 7 | 1.335 ± 0.011 ms | 0.415 ± 0.003 ms | 69% |
| 1,024 | 10 | 14.946 ± 0.134 ms | 3.033 ± 0.021 ms | 80% |

이 측정에서는 데이터셋이 커질수록 속도 차이가 커졌습니다.

### 레이블 잡음에 대한 정확도

속성 10개, 관련 속성 10개:

| 손상된 레이블 | `dtl` | `my-dtl` | 차이 |
| ---: | ---: | ---: | ---: |
| 30% | 69.9% | 51.3% | -18.6%p |
| 50% | 50.0% | 50.1% | +0.1%p |
| 70% | 30.0% | 49.1% | +19.1%p |

속성 10개, 관련 속성 5개:

| 손상된 레이블 | `dtl` | `my-dtl` | 차이 |
| ---: | ---: | ---: | ---: |
| 30% | 69.9% | 77.5% | +7.6%p |
| 50% | 50.0% | 51.8% | +1.8%p |

가장 큰 향상은 관련 속성 10개와 극단적 잡음이 결합된 조건에서 나타났습니다. 같은 구성의 잡음 30% 조건에서는 성능이 크게 하락하므로 일반적인 정확도 향상을 주장할 수는 없습니다.

## 해석

- **확인됨:** 기록된 시간 실험에서 `my-dtl`이 일관되게 더 빨랐습니다.
- **부분적으로 지지됨:** 한 극단적 잡음 조건에서는 `dtl`보다 훨씬 강건했습니다.
- **일반적 주장으로는 기각됨:** 잡음 수준과 제한된 데이터 조건 전반에서 정확도가 향상되지는 않았습니다.
- **공학적 교훈:** 정규화 강도는 학습 데이터 크기만으로 정하기보다 검증 데이터로 선택해야 합니다.

## 타당성의 한계

- 외부 벤치마크가 아닌 의사 난수 합성 Boolean 데이터셋을 사용했습니다.
- 잡음 평가에서 레이블을 복원한 전체 생성 데이터로 평가하므로 학습 데이터와 평가 데이터가 겹칩니다.
- 기본 난수 시드 하나만 사용해 생성된 가설 간 변동성을 충분히 확인하지 못했습니다.
- 실행 시간은 환경에 따라 달라집니다.
- 공유 깊이 카운터는 실제 가지 깊이를 나타내지 않습니다.
- 평가 도구의 통계 출력이 이 보고서에 보존되어 있지 않으므로 백분율 차이를 통계적 유의성의 증거로 해석하면 안 됩니다.

## 다음 단계

1. 공유 가변 상태 대신 재귀 인자로 가지 깊이를 전달합니다.
2. 검증 분할 또는 사후 가지치기로 최대 깊이를 선택합니다.
3. 각 구성을 여러 시드로 반복하고 신뢰 구간을 보고합니다.
4. 합성 데이터뿐 아니라 외부 범주형 데이터셋에서도 평가합니다.
5. 이득비만 적용한 경우, 성장 제어만 적용한 경우, 두 방법을 결합한 경우를 절제 실험으로 비교합니다.
